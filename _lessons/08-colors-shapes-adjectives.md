## Adjective agreement: the -e rule

This is one of Dutch's quirkiest grammar rules, and it connects directly to the de/het system from [[04-articles-pronouns-sentence-structure]]. When an adjective sits **directly before a noun**, it usually gets an **-e** ending:

| Situation | Rule | Example |
|---|---|---|
| de-word (any) | always add -e | de rode auto, een rode auto |
| het-word, definite (het/dit/dat) | add -e | het rode huis |
| het-word, indefinite (een), singular | **no** -e (the one exception) | een rood huis |
| het-word, plural | add -e (plurals always take de) | de rode huizen |

> 💡 Think of it in three cases: **de-words → always -e**. **het-words → -e except after "een"**. Once you internalize "een + het-word = no -e", the rest is automatic.

## Summary

- Colors and shapes are core, high-frequency vocabulary — use them to describe everything around you.
- Adjective + noun: add **-e** almost always; the only exception is **een + het-word singular** (een rood huis).
