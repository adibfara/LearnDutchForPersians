Dutch spelling is very regular once you learn its sound rules — much more predictable than English. Persian speakers have an advantage with some sounds (like the guttural g), but Dutch vowels take practice because Persian has fewer vowel distinctions.

<span dir="rtl" lang="fa">املای هلندی وقتی قوانین صدایی آن را یاد بگیرید بسیار منظم است — قابل پیش‌بینی‌تر از انگلیسی. فارسی‌زبانان در برخی صداها (مثل g گلویی) مزیت دارند، اما مصوت‌های هلندی به تمرین نیاز دارند چون فارسی مصوت‌های کمتری دارد.</span>

## The alphabet / <span dir="rtl" lang="fa">الفبا</span>

| Letter | Dutch name | Sounds roughly like |
|---|---|---|
| a | aa | Persian «آ» short |
| b | bee | English b |
| c | see | s (before e/i) or k |
| d | dee | English d |
| e | ee | Persian «اِ» / English 'e' in 'bed' |
| f | ef | English f |
| g | gee | guttural, like Persian خ |
| h | haa | English h |
| i | ie | short i, like 'sit' |
| j | jee | like English 'y' in 'yes' |
| k | kaa | English k |
| l | el | English l |
| m | em | English m |
| n | en | English n |
| o | oo | Persian «او» short |
| p | pee | English p |
| q | kwee | rare, like 'kw' |
| r | er | rolled or guttural r |
| s | es | English s |
| t | tee | English t |
| u | uu | rounded, like French 'u' |
| v | vee | soft, between v and f |
| w | wee | soft v-like sound |
| x | iks | rare |
| y | ygrek / ie | rare, i-like |
| z | zet | English z |

> ⚠️ **False friend for Persian speakers:** Dutch **j** is *not* like English j — it sounds like English **y** (as in "yes"). So "ja" (yes) sounds like "yaa", not "jaa".

## Key vowel combinations / <span dir="rtl" lang="fa">ترکیب‌های مصوت کلیدی</span>

| Combo | Example | Sounds like |
|---|---|---|
| ij / ei | mijn, klein | English "eye" (ai) |
| ui | huis, uit | rounded "öy" — uniquely Dutch |
| eu | deur, leuk | French eu / German ö |
| oe | boek, goed | English "oo" as in "boot" |
| ou / au | koud, blauw | English "ow" as in "how" |
| aa | maan | long "aa", like Persian «آ» drawn out |
| ee | been | like English "ay" but pure, no glide |
| oo | rood | like English "oh" but pure |

## The guttural g/ch

Dutch **g** and **ch** are pronounced far back in the throat — a sound Persian speakers already know well from **خ** (kheh) in words like خانه. Practice: **goed** (good), **acht** (eight), **lachen** (to laugh).

## Example words to practice out loud

| Dutch | Pronunciation hint | English | Persian |
|---|---|---|---|
| goedemorgen | KHOO-de-mor-khen | good morning | صبح بخیر |
| huis | höys | house | خانه |
| mijn | mine | my | مال من |
| lekker | LEK-ker | tasty / nice | خوشمزه |
| water | VAA-ter | water | آب |

## Summary

- Dutch spelling is regular — learn the sound rules once, read anything.
- **j** = English "y", **g/ch** = guttural like Persian خ.
- The trickiest sounds are **ui**, **eu**, and the pure (non-gliding) **ee/oo** — practice these daily.
